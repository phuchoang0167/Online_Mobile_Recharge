# Data Flow Diagrams

- `FLOWCHART_SYMBOLS.md` — flowchart symbol legend (English) used by all diagrams
- `DATA_FLOWCHART.mmd` — high-level overview of major domains and layers
- `DATA_FLOW_LOGIN.mmd` — login / register / verify + session + email link
- `DATA_FLOW_PRODUCT_PURCHASE.mmd` — product browsing + checkout + feedback
- `DATA_FLOW_GUEST_CHECKOUT.mmd` — guest topup checkout (card/paypal)
- `DATA_FLOW_POSTPAID_PAYMENT.mmd` — postpaid checkout + pay flow
- `DATA_FLOW_FEEDBACK_SUPPORT.mmd` — contact/feedback and admin feedback review
- `DATA_FLOW_USER_SERVICES.mmd` — user dashboard + profile/cards + DND/caller tune
- `DATA_FLOW_ADMIN_OPERATIONS.mmd` — admin dashboard + user/transaction operations

Paste each `.mmd` file into Mermaid Live Editor to render and capture screenshots. Use `FLOWCHART_SYMBOLS.md` for the symbol legend.
